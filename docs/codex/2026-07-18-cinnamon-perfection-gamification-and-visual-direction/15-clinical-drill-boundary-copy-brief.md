# Cinnamon clinical-drill boundary copy brief

Review concise English UI copy for three authored medical-English drills. The app must not diagnose, triage, interpret ECGs, rank differentials, grade clinical competence, or direct care. It may teach wording and organization using fictional, clearly labeled examples. Mature, calm, plain international English; no shame or fake automation.

Return recommended copy for each screen: title, one-sentence instruction, input label/placeholder, button label, and neutral reference feedback.

1. Handoff structure: a fictional case excerpt; learner rewrites it as one concise handoff opening containing the main concern, two supporting facts, and one clear request. The button only reveals an authored model structure.
2. Waveform language: an abstract authored waveform illustration, explicitly not an ECG or interpretation task. Learner describes visible shape using words such as rise, fall, peak, and level segment. The button only reveals a wording cue.
3. Terminology study order: four medical terms are bundled examples. Learner arranges a personal study order; the app does not rank likelihood or recommend a differential. The button confirms the saved-on-screen order and explains that no clinical inference was made.
